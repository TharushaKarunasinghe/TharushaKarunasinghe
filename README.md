I design and ship production-grade agentic systems, multi-tenant RAG pipelines, and full-stack AI microservices that handle real client workloads.

## Featured Projects

<details>
<summary><strong>⬡ Amathus — LangGraph Agentic AI Microservice (Live B2B SaaS)</strong></summary>

<br/>

Amathus is a production-grade AI microservice powering a B2B SaaS platform built for Code Media's enterprise clients. I own the entire AI layer — architecture, implementation, integration, and deployment — as the sole AI Backend Engineer on this live commercial product.

The system is built around a stateful LangGraph agentic loop that routes client queries across a multi-tenant RAG pipeline, manages per-tenant conversation memory, and triggers integrations with Gmail, Google Calendar, and WhatsApp Business API. Each tenant's data is fully isolated at the ChromaDB collection level. The LLM layer is accessed via OpenRouter with a custom fallback chain across providers, ensuring zero single-point-of-failure in inference.

| Attribute | Detail |
|:---|:---|
| **Stack** | Python, FastAPI, LangGraph, LangChain, ChromaDB, OpenRouter, SQLite, Sentence Transformers |
| **Scale** | Multi-tenant architecture — isolated RAG and memory per B2B client |
| **Performance** | Sub-second retrieval via optimized vector indexing; async FastAPI request handling |
| **Security** | Tenant-level data isolation; environment-scoped secrets; webhook signature validation |
| **Impact** | Live client deliverable in active production; full Gmail + Calendar + WhatsApp integrations verified end-to-end |
| **Repository** | [github.com/TharushaKarunasinghe/amathus-ai-service](https://github.com/TharushaKarunasinghe/amathus-ai-service) |

<details>
<summary><strong>⬡ Sinhala Answer Scorer — 4-Agent NLP Evaluation Pipeline</strong></summary>

<br/>

An autonomous NLP scoring system for evaluating Sinhala-language student answers against a knowledge base grounded in Colonial Sri Lanka history. The pipeline is built around four specialized agents — RetrievalAgent, OntologyAgent, ScoringAgent, and ExplanationAgent — that collaborate to produce structured, explainable assessments.

The OntologyAgent interfaces with a hand-crafted OWL ontology (12 classes, 48 named individuals) via owlready2, enabling logic-based semantic reasoning beyond pure vector similarity. The system uses nomic-embed-text for Sinhala embeddings and SinGemma as the LLM backbone, making it one of the few agentic NLP systems designed specifically for low-resource Sinhala language processing.

| Attribute | Detail |
|:---|:---|
| **Stack** | Python, LangChain, ChromaDB, nomic-embed-text, SinGemma, owlready2, OWL ontology, Streamlit |
| **Scale** | 12-class OWL ontology, 48 named individuals; multi-agent orchestration with LangGraph |
| **Performance** | Hybrid scoring — semantic retrieval combined with logic-based ontology reasoning |
| **Security** | Local inference via Ollama; no data exfiltration; self-contained pipeline |
| **Impact** | Graded university NLP assignment; novel approach to Sinhala automated assessment |
| **Repository** | [github.com/TharushaKarunasinghe/sinhala-answer-scorer](https://github.com/TharushaKarunasinghe/sinhala-answer-scorer) |

</details>

<summary><strong>⬡ Tea Leaf Quality Sorter — Edge Computer Vision System (FYP)</strong></summary>

<br/>

A real-time automated tea leaf quality classification system deployed on a Raspberry Pi 4 with a mechanical conveyor integration. The system uses a dual-model architecture: YOLOv8 Nano for real-time object detection and localization, combined with VGG16 for fine-grained quality classification under controlled 5500K LED illumination.

This is my final-year project (FYP) at KDU — a full hardware-software integration designed for deployment in Sri Lanka's tea industry, where manual leaf sorting remains a labour-intensive bottleneck. The Streamlit operator interface provides real-time classification feedback, grading visualizations, and session logging for production floor supervisors.

| Attribute | Detail |
|:---|:---|

| **Scale** | 947-image augmented dataset; MobileNetV2 baseline achieved 97.5% test accuracy |
| **Performance** | Real-time inference on edge hardware; optimized for Raspberry Pi 4 resource constraints |
| **Security** | Fully offline / air-gapped deployment; no cloud dependency in production |
| **Impact** | Full hardware-software integration; targets automation of manual labour in tea production |
